Public API

BayesianVectorAutoregressions.JohansenResult — Type
JohansenResult

Output of johansen_trace_test: the sufficient statistics for choosing a cointegrating rank and the estimated cointegrating vectors. Element $r+1$ of each statistic vector (and row $r+1$ of each critical-value matrix) refers to the null hypothesis $H_0: \text{rank} \le r$, $r = 0, \ldots, n-1$.

  • trace_stats — $LR_{trace}(r) = -T_{eff}\sum_{i=r+1}^{n}\log(1-\hat\lambda_i)$.
  • max_eig_stats — $LR_{max}(r) = -T_{eff}\log(1-\hat\lambda_{r+1})$.
  • eigenvals — $\hat\lambda_1 \ge \cdots \ge \hat\lambda_n$, the squared canonical correlations between $\Delta y_t$ and $y_{t-1}$.
  • β — the $n \times n$ matrix of eigenvectors; column $i$ belongs to $\hat\lambda_i$, so β[:, 1:r] are the estimated cointegrating vectors under rank $r$. Normalized as $\hat\beta' S_{11} \hat\beta = I$.
  • trace_cv, max_eig_cv — $n \times 3$ MacKinnon, Haug & Michelis (1999) critical values at the 90%, 95%, and 99% levels (NaN where $n-r > 12$).
  • T_eff — the effective sample size $T-p$ used by every statistic.
  • include_constant — whether an unrestricted constant was included.

Read it with @unpack trace_stats, eigenvals, β = result, or field access.

BayesianVectorAutoregressions.johansen_trace_test — Method
johansen_trace_test(df::DataFrame, end_vec::Vector{Symbol}, p::Int; include_constant = true)

Johansen (1988, 1991) reduced-rank test for cointegration among the endogenous variables, based on the VECM with $p$ lags in levels,

$\Delta y_t = \Pi y_{t-1} + \sum_{i=1}^{p-1}\Gamma_i\,\Delta y_{t-i} + c + \varepsilon_t,$

where the constant $c$ is present (and unrestricted) when include_constant = true. $\Delta y_t$ and $y_{t-1}$ are each regressed on the short-run terms, giving residuals $R_{0t}$ and $R_{1t}$ and moment matrices $S_{ij} = T_{eff}^{-1}\sum_t R_{it}R_{jt}'$ with $T_{eff} = T - p$. The eigenvalues $\hat\lambda_1 \ge \cdots \ge \hat\lambda_n$ and eigenvectors $\hat\beta$ solve

$\left|\lambda S_{11} - S_{10}S_{00}^{-1}S_{01}\right| = 0, \qquad \hat\beta' S_{11}\hat\beta = I,$

and the statistics for $H_0: \text{rank}(\Pi) \le r$ are

$LR_{trace}(r) = -T_{eff}\sum_{i=r+1}^{n}\log(1-\hat\lambda_i), \qquad LR_{max}(r) = -T_{eff}\log(1-\hat\lambda_{r+1}).$

Choose the rank as the first $r$ whose statistic falls below its critical value. Critical values are the MacKinnon, Haug & Michelis (1999) asymptotic quantiles for the matching deterministic case (an unrestricted constant, or no deterministic terms when include_constant = false). Columns of β can be passed as H to dummy_long_run. Returns a JohansenResult.

BayesianVectorAutoregressions.johansen_critical_values — Method
johansen_critical_values(n::Int, include_constant::Bool)

Looks up MacKinnon, Haug & Michelis (1999) critical values for the Johansen trace and maximum-eigenvalue statistics of an $n$-variable system. Row $r+1$ of each returned $n \times 3$ matrix holds the 90%, 95%, and 99% quantiles for $H_0: \text{rank} \le r$, i.e. for $n-r$ common stochastic trends; rows with $n-r > 12$ (beyond the published table) are NaN. include_constant selects the unrestricted-constant case (true) or the no-deterministic-terms case (false). Returns (trace_cv, max_eig_cv).
